# Voalack visual assets

The original **Handoff** identity uses a cobalt receiving dock and a separate incoming bar. The display wordmark is **voalack.** The complete original vector construction and usage guidance are in [BRAND.md](BRAND.md).

| Asset | Purpose |
| --- | --- |
| `readme-hero-light.png`, `readme-hero-dark.png` | Wide README artwork, selected by the reader's colour scheme |
| `voalack-logo-light.svg`, `voalack-logo-dark.svg` | Canonical transparent wordmarks with outlined lettering |
| `voalack-logo-mono.svg`, `voalack-logo-white.svg` | One-colour wordmarks |
| `voalack-mark*.svg` | Standalone symbol in colour, reversed and monochrome forms |
| `favicon.svg`, `voalack-app-icon.svg`, `voalack-icon-256.png` | Small-site icon, vector icon master and ready-to-use PNG |
| `acknowledgement-flow.svg` | Precise illustration of the planned feed and human ACK path |
| `delivery-outcomes.svg` | Planned outcomes; a local ACK does not establish remote success |
| `badge-*.svg` | Static stage, prototype Python and planned storage labels; not CI or release badges |
| `brand-spec.json`, `generate_brand.py` | Palette, geometry and reproducible vector source |
| `generate_diagrams.py` | Editable, deterministic diagram source |

The diagrams are planned architecture illustrations, not product screenshots. Their source emits `planned-acknowledgement-flow.svg` and `acknowledgement-outcomes.svg`; those map to the two distributed names above. Generate in a temporary directory and inspect the output before copying it over reviewed assets. Basic vector generation uses Python's standard library; optional previews use Inkscape and, for brand proofs, Pillow.

The canonical logo is flat. The PNG banners are spatial illustrations created for the project; their artwork is not generated by the vector scripts. Preserve aspect ratios, contrast and the symbol's clear gap. Keep badges tied to current evidence.
